Game integration

Server-side code validation

REDEMPTION ENDPOINT
POST /api/game/redeem
Authorization: Bearer YOUR_GAME_API_KEY
Content-Type: application/json

{
  "code": "ZAR-ABCDE-FGHIJ"
}
Keep the API key inside a Roblox server Script or secure server configuration. Never expose it in a LocalScript, GUI, or replicated storage.

Roblox Setup

Configure how players enter THE ZAR

These settings are saved to your website and exposed only to authenticated Roblox server scripts. The Roblox game still needs a server Script and screen LocalScript that read these settings before they can enforce the gate.

Response example

{
  "ok": true,
  "type": "giveaway",
  "reward": "Free Early Access"
}

The endpoint validates and consumes a code use. Your Roblox server must then decide what reward to grant and prevent the same player from claiming the reward twice.

The API key must be configured as a Cloudflare Worker secret named GAME_API_KEY. This admin panel never displays the secret.
